# Checklist Breve de Validación

## 1) Checklist de pruebas mínimas
- [ ] El programa corre al menos una vez sin fallar.
- [ ] Se validó al menos una entrada válida.
- [ ] Se validó al menos una entrada inválida.
- [ ] Se registró resultado esperado vs. obtenido.

## 2) Checklist de documentación
- [ ] `docs/propuesta.md` está completo.
- [ ] `docs/caso_de_uso.md` está completo.
- [ ] `docs/plan_de_pruebas.md` contiene casos de prueba.
- [ ] El alcance mínimo está claramente definido.

## 3) Checklist de ejecución
- [ ] `scripts/run.sh` funciona en su versión adaptada.
- [ ] El archivo principal en `src/` corresponde al lenguaje elegido.
- [ ] No se usaron frameworks ni dependencias complejas.

## 4) Checklist de entrega final
- [ ] Repositorio ordenado y sin archivos basura.
- [ ] README actualizado y coherente con el proyecto.
- [ ] Evidencia de pruebas incluida en documentos.
- [ ] Proyecto pequeño, viable y alineado al objetivo.
